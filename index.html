How it works

A few constraints keep this collection portable and approachable.

01

Self-contained

HTML, CSS, and JavaScript live together so every tool can be copied, reviewed, and hosted as a single page.

02

Local by default

Files, clipboard data, and transformations stay in the browser whenever the platform makes that possible.

03

Easy to remix

Small, direct source files make proven patterns easier to adapt to the next useful problem.
